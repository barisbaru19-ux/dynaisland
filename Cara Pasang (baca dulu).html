Cara pasang DynaIsland

"Dynamic Island" ala iPhone untuk MacBook. Pemasangannya sekitar satu menit dan tidak perlu Xcode atau akun developer.

Cara tercepat: satu baris

Buka Terminal (⌘ + Space, ketik Terminal), tempel baris ini, lalu tekan Enter:

curl -fsSL https://raw.githubusercontent.com/barisbaru19-ux/dynaisland/main/install.sh | bash

App siap pakai langsung diunduh, dipasang, dan dibuka dalam beberapa detik. Tidak perlu Xcode, dan tidak ada peringatan "damaged". Langkah-langkah di bawah hanya untuk memasang dari file zip.

Yang dibutuhkan

  • MacBook dengan chip Apple (M1 atau lebih baru). Paling bagus di MacBook yang ada notch kameranya.
  • macOS 12 Monterey atau lebih baru.
  • Internet, hanya kalau Command Line Tools dari Apple belum terpasang (gratis, sekali saja).

Langkah pemasangan

1

Buka zip-nya

Klik dua kali DynaIsland.zip. Folder DynaIsland akan muncul di sebelahnya. Buka folder itu.

2

Klik dua kali "Pasang DynaIsland"

Klik dua kali Pasang DynaIsland. Terminal akan terbuka sendiri lalu app di-build, dipasang ke folder Applications, dan langsung dijalankan. Kalau berhasil, muncul notifikasi "Sudah terpasang".

Muncul peringatan? Ini normal untuk file pertama kali dibuka setelah dikirim lewat WhatsApp, AirDrop, atau browser. Filenya tidak rusak. macOS hanya belum mengenalnya karena tidak ditandatangani akun developer Apple.

⚠️
"Pasang DynaIsland.command" is damaged and can't be opened.
WhatsApp created this file today
CancelMove to Trash

Pesannya bisa juga "Not Opened" atau "Apple could not verify…". Pilih Cancel / Done, jangan Move to Trash.

Lalu jalankan lewat Terminal, cukup sekali:

  1. Buka Terminal: tekan ⌘ + Space, ketik Terminal, tekan Enter.
  2. Ketik bash lalu satu spasi. Jangan tekan Enter dulu.
  3. Seret file Pasang DynaIsland dari Finder ke jendela Terminal. Alamatnya terisi sendiri, kira-kira seperti ini:
% bash /Users/kamu/Downloads/DynaIsland/Pasang\ DynaIsland.command
  1. Tekan Enter. Pemasangan berjalan seperti biasa.

Setelah sekali lewat Terminal, file-file di folder ini bisa langsung diklik dua kali.

3

Kalau diminta memasang Command Line Tools

Kalau compiler Swift dari Apple belum ada, muncul jendela dari Apple. Klik Install dan tunggu sampai selesai (beberapa menit, tergantung internet). Setelah itu ulangi langkah 2.

Kalau jendela ini tidak muncul, berarti sudah terpasang. Lanjut saja.

4

Selesai

Island hitam muncul di sekitar kamera (atau pil kecil di tengah atas layar untuk MacBook tanpa notch), dan ada ikon di menu bar. Arahkan kursor ke notch untuk membuka island.

Beberapa izin akan ditanyakan. Klik Allow / OK untuk semuanya:

  • Calendars: untuk hitung mundur meeting dan tombol Gabung.
  • Downloads dan Desktop folder: supaya download dan screenshot baru langsung masuk Shelf.
  • Control Spotify / Music (saat pertama memutar musik): supaya tombol musik dan cover lagu berfungsi.

Setelah update, izin ini kadang ditanyakan lagi. Itu normal.

Supaya otomatis jalan setiap Mac menyala: klik ikon kapsul, pilih Buka saat login.

Memperbarui ke versi baru

Lakukan langkah 1 dan 2 dengan zip yang baru. Versi lama tertimpa sendiri, tidak perlu dihapus dulu. Peringatan di langkah 2 bisa muncul lagi untuk setiap zip baru. Pakai cara Terminal yang sama.

Menghapus

Klik dua kali Hapus DynaIsland di folder yang sama. App, pengaturan, dan izinnya ikut dihapus. Kalau kena peringatan, pakai cara Terminal di langkah 2 dengan file Hapus DynaIsland.

Kalau ada masalah

Muncul "Build gagal" Salin atau screenshot pesan error di jendela Terminal, lalu kirim ke orang yang memberimu file ini.
Island tidak terlihat Cek ikon kapsul di menu bar. Kalau ada, buka menunya dan pastikan Sembunyikan saat idle tidak dicentang. Kalau tidak ada, ulangi langkah 2.
Tombol musik tidak berfungsi Klik ikon kapsul → Izin Automation (kontrol musik)…, lalu nyalakan DynaIsland untuk Spotify / Music.
Meeting tidak muncul di tab Agenda Buka tab Agenda dan klik Izinkan / Buka pengaturan, lalu nyalakan DynaIsland di Privacy & Security → Calendars. Akun Google/Outlook harus sudah ditambahkan di app Calendar.
Download / screenshot tidak masuk Shelf Nyalakan DynaIsland di Privacy & Security → Files and Folders (Downloads dan Desktop). Pastikan Download & screenshot ke Shelf dicentang di menu kapsul.
Lagu dari YouTube / browser tidak muncul Memang belum bisa. Sejak macOS 15.4, Apple menutup akses "Now Playing" untuk app pihak ketiga. Yang terbaca hanya app Spotify dan Apple Music.
Izin Automation ditanyakan lagi setelah update Normal, karena app di-build ulang. Klik OK lagi.

Apakah aman?

Peringatan dari macOS muncul karena app ini tidak berasal dari App Store dan tidak ditandatangani akun developer Apple, bukan karena isinya berbahaya. Semua kode ada di folder Sources dan bisa dibaca. Script pemasangnya (Pasang DynaIsland dan build.sh) bisa dibuka dengan TextEdit untuk melihat apa saja yang dijalankan.

App ini hanya memakai internet untuk mengambil gambar cover lagu Spotify. Jadwal sholat dihitung di Mac kamu tanpa internet.

Panduan lengkap fitur dan pengaturan ada di README.md di folder yang sama.
